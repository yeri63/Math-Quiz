# Math Quiz
<div align="center">
  
![Screenshot of Math Quiz](https://github.com/yeri63/Math-Quiz/blob/master/mathquiz.png)
</div>
<p>This was designed to help my daughter's perform their math drills to learn addition, subtraction, multiplication and division tables, with a goal of decreasing the time needed to recite the answer. In effect, this is simulates a deck of Math flash cards, where one side of each card has the problem, and the other side has the answer.</p>
<p>To use, select a which table to practice, then view the equation and say the answer. Press Update button to check, then Update again to generate the next equation. The goal is to correctly answer every question in under a second.</p>
