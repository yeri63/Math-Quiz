# Math Quiz
<div align="center">
  
![Screenshot of Math Quiz](https://github.com/yeri63/Math-Quiz/blob/master/mathquiz.png)
</div>
Math drills to learn addition, subtraction, multiplication and division tables, and decrease the time needed to recall the answer. In effect, this is simulates Match flash cards, where one side of each card has the problem, and the other side has the answer. 

To use, select a which table to practice, then view the equation and say the answer. Press Update button to check, then Update again to generate the next equation. The goal is to correctly answer every question in under a second.
