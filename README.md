# Math Quiz
<div align="center">
  
![Screenshot of Math Quiz](https://github.com/yeri63/Math-Quiz/blob/master/mathquiz.png)
</div>
<p>This was designed to help my daughter's perform their math drills to learn addition, subtraction, multiplication and division tables when they were in grade school. Their goal was to gradually decrease the time needed to recite the answer. In effect, this is simulates a deck of Math flash cards, where one side of each card has the problem, and the other side has the answer.</p>
<p>To use, select a which table to practice. The application will then display a random equation from that table, wait for the user to view and say the answer. To check, press the Update button, and Update again to generate the next equation. The goal is to correctly answer every question in under a second.</p>
